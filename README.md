# Healthcare Business Intelligence | Executive Revenue Dashboard

## Project Overview

An interactive executive-level Power BI dashboard designed to monitor healthcare business performance, analyze revenue trends, and evaluate customer and regional performance.

This project demonstrates end-to-end Business Intelligence development, including data visualization, DAX calculations, time intelligence, KPI development, and interactive report navigation.

**Data Disclaimer:** This portfolio project uses synthetic data created for demonstration purposes. It does not contain actual company, patient, or confidential business information.

## Key Dashboard Features

- Executive KPI cards for monitoring business performance.
- Dynamic reporting across Current Month, Current Quarter, Current Year, and Rolling 12 Months.
- Revenue trend analysis and prior-year comparisons.
- Year-over-year revenue variance and percentage calculations.
- Regional and account-segment performance analysis.
- Interactive navigation between executive summary and revenue detail pages.
- Drillthrough functionality for deeper analysis.
- Dynamic DAX measures and time intelligence.

## Business Value

The dashboard provides stakeholders with a centralized view of business performance, allowing them to:

- Monitor revenue performance across reporting periods.
- Compare current performance against prior-year results.
- Identify regional and account-segment trends.
- Evaluate changes in key business metrics.
- Navigate from executive-level reporting into detailed performance analysis.
